Palma Heat — an open-world crime game set in Palma, a sun-soaked coastal city. Explore the city on foot and by car, steal five named cars, outrun police cruisers and a searchlight helicopter through a 0–5 wanted level, and work six chained missions for Lucía. Traffic, 44 pedestrians, a beach, a pier, a ferris wheel, a warehouse lot, a casino and a full HUD with minimap, police response panel, radio and REP progression — all offline, all original.

## Run it

```sh
node serve.ts
```

Then open http://localhost:8080 — W A S D to move and drive, E to enter and exit cars, F to punch, 1–4 to switch weapons, click to shoot, P to pause, M to switch radio.
